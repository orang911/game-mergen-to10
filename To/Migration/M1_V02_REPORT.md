# M1 v02：棋盘反馈补齐与回归

## 本轮完成

- 移植原版整层 SDF 阴影：最多 25 个方块，跟随位置、缩放和透明度，取覆盖率最大值，不叠加压黑。
- 移植合成残影：复用原版背板、字形和隐藏阴影纹理；保留原始图集 UV 行为、排序、0.96 初始缩放、0.74 收缩、0.38 最大透明度以及 0.18 秒淡出。
- 阴影/残影不增加玩法，不增加新美术；仍为世界空间棋盘。
- 吸收结束隐藏已吞并视图；重置同步清理残影、震屏和旧方块，避免残留对象。
- 入场采用同一起点的独立错峰，间隔 0.04 秒、下落 0.28 秒；不再逐格等待而累计帧误差。
- 底板改为原版等比裁切；残影/阴影材质处理必要的颜色转换。Unity 工程仍保留 Linear 色彩空间。
- 构建额外检查三个棋盘着色器，不再只依赖 Unity 的 Build Success 状态。

## 已验证

- 冻结 Godot 原生 Tween 生成 132 组位置、缩放和透明度样本，396 项对应断言通过。
- Unity 总计 **14,079 项断言**及 Windows 开发构建通过。
- 470×836、360×800、384×512 三种窗口比例，以及默认图形后端另跑 470×836，全部退出码 0。
- 每轮验证实际相机输出、阴影/残影/高亮像素差分、自动连锁、25 格结算、最终缩放、合成中重置、整盘 25 块合成、残影清理、孤立和 Z 方块拒绝合成、无效操作抖动复位。
- 正式源代码/着色器/图片/音频与验证副本哈希一致，正式场景脚本 GUID 引用有效。

## Godot 图像对照

通过冻结副本实际的 Block、BoardShadowLayer 和 MergeTrailGhost 生成相同尺寸、相同素材、相同布局的参考。
静态残影探针使用 age=0.10、action=0.18、delay=0，并与正常合成截图分开保存。

每通道 0～255 范围的抽样平均绝对误差：

- 背景：1.04。
- 棋盘区域：5.50（修正前 5.75）。
- 残影探针区域：3.07（修正前 4.93）。

**仍非逐像素等价。** 棋盘边缘、半透明合成和过滤存在差异，不能据此宣称美术或真人手感完全验收。未为降低指标而缩放、重采样参考图，也未切换整个项目到 Gamma。

## 失败记录及修复

- First470x836：MaterialPropertyBlock 在 MonoBehaviour 字段构造时创建，运行报错；已移至 Awake。
- Color470x836：颜色函数缺少 URP Color.hlsl 引用；已修复并增加着色器错误构建门禁。
- 这些失败记录保留，不能作为本次通过证据。
- 最新证据以 Final* 目录及 m1-v02-final-build.log 为准。

## 入口与复现

- Unity 场景：Assets/MergeTo10/Scenes/M1BoardParity.unity，打开后按 Play。
- Windows：Builds/M1V02/Windows/MergeTo10M1.exe，完整目录一起使用。
- 完整包：Builds/M1V02/MergeTo10_Unity_M1_v02_Windows.zip。
- 回归截图和结果：Builds/M1V02/Final470x836、Final360x800、Final384x512、FinalDefault470x836。
- Godot 参考及缓动数据：Migration/Reports/M1V02。
- 图像误差：Builds/M1V02/Final470x836/godot-visual-comparison.json。
- 构建日志：Migration/Validation/m1-v02-final-build.log。
- 构建脚本：Migration/Tools/BuildM1.ps1（默认输出 v02；支持 OutputDirectory）。
- 参考生成：用隔离 WorkingGodot 运行 Migration/Tools/CaptureM1VisualReference.gd，并传 --capture-dir。
- 图片为 URP 离屏相机输出，不含临时 IMGUI；仅供实际场景渲染验证，截图期间的帧时长不能当作性能测试。
