# M2 编辑器战斗联调 v01

目标工程：D:/UGit/T0/To。按本轮要求，只在 Unity 编辑器测试，没有打 Windows 测试包。

## 如何测试

1. 打开 Assets/MergeTo10/Scenes/M2BattleParity.unity，点击 Play。
   也可从 Unity 菜单 Merge To 10 → Open M2 Combat Test 打开；切换场景前会询问保存当前修改。
2. Game 窗口建议设 470×836 或接近9:16的竖屏比例。
3. 正常点棋盘：有效合成冻结怪物移动和状态计时，连锁完成后依次发射、命中，全部结算后恢复移动。
4. Five elements：注入五种元素测试批次，不是自然连锁。观察固定槽位发射、不同元素间隔和血条变化。
5. Reset fixture：重置棋盘和测试阵列，并取消旧弹道。Pause/Resume：暂停/恢复；编辑器工具栏暂停也接入时钟边界。
6. 选择 Hierarchy 中 M2CombatFixture，可调整怪物数量、血量和测试起点，运行后点 Reset fixture 生效。
7. Console 的 [M2 HIT] 记录每组元素实际命中的攻击时间和剩余怪物数。

## 实现内容

- 独立新场景，保留 M1BoardParity 与原 SampleScene。
- 复用冻结原版19点路径、道路/门素材，原版小怪速度与终点64像素停止边界。
- 接入实际怪物血量、受击停顿、冰减速、闪电眩晕、毒/火最多4层及状态计时。
- 合成通过 IBoardCombatSink 同步冻结，真实合成快照决定伤害；同元素单槽、保留原贡献。
- 元素顺序火、闪电、暴击、冰、毒；发射组间隔0.15秒，弹道飞行0.14秒后结算。
- 从可见固定槽实时位置出发；冰多目标、火溅射、闪电伤害跳跃、暴击/湮灭计算及死亡换目标。
- 清场不继续发射；测试阵列不会自动生成下一波。
- 新增原版史莱姆18帧行走、8帧受击图集及2.28显示缩放；帧矩形320×320、pitch328、padding4。
- 修复编辑器测试暴露的棋盘吸附回调越过方块销毁问题：协程改由被吸附方块持有。
- 补齐棋盘相机 AudioListener。未更换合成音频素材。
- 原版素材仅复制入 Resources/M2Art，没有生图、重新抠图、修改源PNG或改动冻结Source。

## 验证与限制

最终验证入口：
Migration/Tools/ValidateM2Editor.ps1

该脚本只启动隔离验证工程的 Unity 编辑器，编译后进入 Play Mode，不调用 BuildPipeline.BuildPlayer。
验证报告在 Migration/Reports/M2EditorV01/FinalDelivery，早期轮次保留诊断，不作为最终通过依据。

- 重跑既有战斗基础对照：840事件、200批次，共23,085项检查。
- 新增路径、毒整秒跳伤、冰速度、受击停顿、毒层数定向检查。
- 编辑器实际执行五组发射/命中、冻结期间模拟时钟不变、普通棋盘连锁接战斗、预览中重置取消及无迟到攻击。
- 冻结检查每编辑器帧执行，断言总数随编辑器帧率变化；不将此数量当成新增规则数。
- 470×836离屏截图已检查并据此修正怪物显示比例。
- 最终运行日志仍需结合 editor-result.txt 审查。隔离编辑器启动时出现 UnityEditor.Search.SearchDatabase 的内部索引异常；与游戏脚本无关，未通过删库等方式掩盖。已发现的 CellView MissingReferenceException 已修复并复测。
- 工具栏暂停接入了时钟边界；完整暂停/恢复、焦点丢失、不同屏幕比例仍待人工验收。

## 不是完整战斗版

本场景是明确的固定测试阵列：默认8只、每只120血、首只进度0.42；这些是测试参数，不是正式关卡数值。
尚未接入正式章节波次、刷怪调度、水晶自动攻击/升级、印记、教程和完整UI。

表现仍为联调级：普通弹道直线插值、伤害闪色和血条用于检查逻辑；
原版完整拖尾、连锁电弧、共鸣环/次数文字、命中序列帧、死亡动画、伤害跳字及声画节奏尚未等价迁移。
怪物行走与受击使用原资源，但动作打断/恢复的全部细节仍待逐项对照。
怪物基础状态已实现，完整状态随机差分、Boss/教程特殊规则仍未认证。
因此不能把此场景当作最终手感、美术、平衡或Android性能验收版。
