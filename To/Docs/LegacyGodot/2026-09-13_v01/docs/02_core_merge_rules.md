# 核心合成规则 / Core Merge Rules

更新：2026-08-12

## 一键合成操作

- 点击任意可合成组内方块，即立即将上下左右连通的同等级整组合成，不需要第二次点击确认。
- 实际点击的方块固定为合成结果位置；组内其他方块汇入该位置后消失，结果等级 `+1`。
- 点击没有相邻同级方块的孤立方块时只播放抖动反馈，不保留选中状态，也不触发攻击或棋盘暂停。

## 棋盘与操作

- 棋盘为 5×5；逻辑坐标使用 `Vector2i(x, y)`，`y = 0` 为底行。
- 点击方块会查找上下左右相邻、且等级相同的整组方块；数量不少于 2 时立即合成。
- 点击位置就是本次合成目标；只找到一个方块时不保留选择并播放抖动反馈。
- 被合并方块移动至目标并消失，目标方块等级 `+1`，随后下落并补充。
- 达到当前最高等级 `36 / Z` 的方块不再参与合成。

## 合成攻击

每次有效合成都生成 `MergeAttackEvent`。结果等级决定基础攻击 `B`，合成数量为 `N`；攻击优先命中最靠近水晶的怪物。

| 属性 | 攻击规则 |
|---|---|
| 毒 | N 发连续集火；总直伤 `B × max(1, N-1)`，按 N 发均分。每次有效命中叠 1 层毒，最多 4 层。 |
| 冰冻 | 命中前方 `max(1, N-1)` 个不同目标；每个目标承受完整 `B` 并减速。 |
| 闪电 | 一次主攻击；额外合成量增强主伤害、弹跳数量和保留率。 |
| 暴击 | N 发连续集火；每发独立判定暴击和普通怪湮灭。 |
| 火焰 | N 发连续集火；每发可施加燃烧和范围溅射。 |

连续集火的目标不在存活期间切换；只有目标死亡或抵达水晶后，后续攻击才转向新的最前怪物。无有效目标时，攻击提示仍显示，但剩余发数结束。

## 下落与补充

- 每列由底部向上压实。
- 空格根据当前掉落规则补充新方块。
- 刷新概率、死盘保障和等级上限以 `main_game.gd`、`GameConfig` 以及数值主表为准；不得在其他玩法文档复制一套独立概率。

## 失败、重试与复活

- 失败来源有两个：水晶耐久归零，或棋盘不存在任何可合并的相邻同等级方块。
- 章节内失败重试恢复当前节点检查点；棋盘、水晶、能量、待触发印记和章节强化按检查点恢复。
- 复活入口沿用失败结算流程；不得把复活设计成整章重置。
- 主动返回大厅会结束本次章节运行；中途退出/关闭应用会保存，重启后继续。

## 印记边界

印记不属于方块状态。选择印记后，它存在于唯一的“下一次有效合成”槽位中；该次合成结算印记效果后消耗。完整规则见 `13_skill_imprint_mechanism.md`。
