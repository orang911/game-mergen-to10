# v05 连锁与接力攻击测试说明

当前工程：D:/UGit/UGit/TO10

## 行为

- 一次有效合成冻结怪物移动、状态计时、刷怪、塔自动攻击和战斗计时，结算完成恢复；无效点击不触发。
- 塔蓄力中被打断的自动攻击会在恢复战斗后重新选目标发起。
- 最多五次合成（首次手动一次、自动最多四次），后续合成逐步加快。
- 元素按固定槽位聚合并显示次数，同元素只发射一组强化攻击。
- 火、闪电、暴击、冰、毒依次发射，间隔 0.15 秒；缺少元素跳过。
- 每组弹道独立在飞行结束时结算，保留源合成伤害贡献、暴击计算和持续伤害层。
- 目标死亡后在飞行中重新选取活怪，场上清空则消散并结束；波次切换等待结算结束。
- 共鸣增益仍按不同元素数计算：三种 1.15、四种 1.30、五种 1.50。

## 手机重点验收

1. 怪物快到塔边时合成，演出期间塔不受新伤害，结束后怪物继续行动。
2. 重复火元素汇入同一个图标，次数增加；两种元素不会点亮三元素共鸣。
3. 五种元素按固定位置和顺序攻击，能够分辨每次命中及血条变化。
4. 第一击杀怪后，后续攻击转向活怪；全清时不对空持续攻击。
5. 结算中暂停再恢复、退出再进入、重开，不能卡住或出现遗留元素。
