# 当前开放问题 / Open Questions

更新：2026-08-06

以下问题尚未锁定，但不阻塞第一章当前版本。已确认规则请不要再放回此处，统一查 `00_current_product_baseline.md` 和 `09_decision_log.md`。

## 第一章与续战数值

- 第一章各节点的目标耗时、水晶受击上限和首通率实测是多少？
- 20 波续战从第几波开始出现输出断档、死盘或不可逆漏怪？
- 小/中/大怪的耐久伤害 1/2/3 是否能形成可感知但不挫败的压力？
- 水晶 `1.8 秒 / 30%` 基线与星核蒸汽炉 `+10%` 是否足够让玩家看懂强化价值？

## 卡牌与印记

- 当前 12 张运行卡的获得频率、选择率和胜率提升分别是多少？
- 印记满能量后的三选一是否应始终只出印记，还是在非教学章节允许水晶卡？
- 当前单一待触发槽位是否需要在 HUD 上增加更明确的“下一次合成”说明？
- 16 张目标卡池是否真的需要扩展；若需要，先补哪四张？
