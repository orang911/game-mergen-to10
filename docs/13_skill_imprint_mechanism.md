# 能量与棋盘印记机制 / Energy And Imprint Mechanism

更新：2026-08-06

## 核心流程

```text
获得能量 → 光点飞抵 HUD → 能量达到 100 → 打开选择弹窗
→ 选择一个印记 → 进入“下一次有效合成”槽位
→ 下一次有效合成立即结算印记 → 槽位清空
```

- 能量上限为 100；选择后归零。
- 能量光点未抵达 HUD 前，不提前打开选择。
- 选择弹窗暂停战斗；关闭选择后继续原战斗状态。
- 同时只允许一个待触发印记。已有印记时，满能量不再打开第二次选择。
- 消耗待触发印记后，若能量已经满，则重新请求选择。

## 能量来源

- 普通攻击击杀怪物：`+5`。
- 合成结果高于合成开始前棋盘最高等级：`6 × (合成数量 - 1)`。
- 普通命中、水晶普通命中、技能造成伤害或技能击杀不产能。

## 当前印记池

| 印记 | 合成时效果 |
|---|---|
| 星阶铸锤 | 提升本次合成结果等级。 |
| 万象数盘 | 记录印记合成前数字，并统一其他非保留方块数字。 |
| 命运魔箱 | 重排棋盘，保证至少存在一组可合成方块。 |
| 双生晶模 | 将相邻非最高级方块变为结果块数字。 |
| 王城魔炮 | 攻击最前怪物一次。 |
| 龙焰投石 | 攻击一组前排怪物并附加燃烧。 |

## 第一章教学与解锁

- `1-3` 第一波：脚本补满能量，固定获得星阶铸锤。
- `1-3` 第二波：脚本补满能量，在星阶铸锤与王城魔炮中选择。
- `1-4` 护卫波、小 Boss 波和 `1-5` 大 Boss 波：能量满后允许随机印记选择。
- `1-1` 至 `1-3` 的非脚本波不开放随机选择，以避免覆盖教学节奏。

## 已废弃的旧规则

印记不再附着棋盘格、不随方块下落或重排、不使用队列。任何提到“待附着队列”“印记方块”的文档均是历史规则。
