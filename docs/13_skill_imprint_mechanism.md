# 统一卡池、技能印记与能量机制

日期：2026-07-16  
状态：20 波单关卡第一版规则已确定并接入运行时。

> 2026-07-17 更新：本文中的 9 张总卡池仍代表当前运行时。水晶卡已经确认新的 8 张物品化设计，目标总卡池将扩展为 13 张；尚未完成代码替换，设计见 `16_crystal_tower_card_design_2026-07-17.md`。

## 1. 单关卡节奏

一关共 20 波。进入第 5、10、15、20 波之前，分别发放一次节点卡牌奖励：

```text
清完第4波 → 节点三选一 → 第5波
清完第9波 → 节点三选一 → 第10波
清完第14波 → 节点三选一 → 第15波
清完第19波 → 节点三选一 → 第20波
```

第20波清空后结束本关，不再循环回第1波。

## 2. 统一卡池

棋盘卡和水晶卡不再使用两个互斥的选择系统。九张卡进入同一个总卡池，共用卡牌弹窗和选择流程；卡牌根据自身类型决定后续行为：

- 棋盘卡：进入待附着队列，下一次合成结果块获得印记。
- 水晶卡：卡牌飞抵水晶塔后立即应用当前对局强化。
- 元素棱镜：选择卡牌后继续选择火、冰、毒、雷属性。

两种奖励只改变抽取倾向和品质，不改变总卡池归属。

### 能量选择

能量满后进行三选一：

- 前两张固定从 5 张棋盘卡中抽取。
- 第三张从九张总卡池抽取，因此有概率出现水晶卡。
- 品质以普通为主，优秀次之，稀有概率出现。

能量选择是高频、偏棋盘的战术奖励。

### 节点选择

进入第5、10、15、20波前进行三选一：

- 前两张固定从 4 张水晶卡中抽取。
- 第三张从九张总卡池抽取，因此仍可能出现棋盘卡。
- 节点奖励不出现普通品质，至少保证一张稀有水晶卡。

节点选择是低频、高品质、偏水晶塔的核心成长奖励。

## 3. 卡牌品质

品质分为普通、优秀、稀有。品质进入卡牌状态和运行时效果，不只是显示标签。

- 普通：基础效果。
- 优秀：中等强化。
- 稀有：强效果或额外目标/持续时间。

棋盘卡品质示例：

- 晶核跃升：普通/优秀 +1 级，稀有 +2 级。
- 碎片重铸：最低等级方块分别 +1、+2、+3。
- 寒星冲击：品质提高目标数、伤害、减速比例和持续时间。
- 同频汇聚和棋盘回响：高品质提高批量整理强度。

水晶卡品质示例：

- 星核增幅：攻击力 +15% / +25% / +35%。
- 迅流脉冲：攻击间隔乘以 0.90 / 0.82 / 0.75。
- 双重折射：额外目标 +1 / +1 / +2。
- 元素棱镜：临时属性持续 1 / 2 / 3 波。

同一张卡再次被选中时继续叠加其当前对局效果；本轮暂不实现长期存档成长。

## 4. 能量来源

能量上限为 100，不溢出。

- 普通攻击击杀怪物：+5。
- 普通攻击附带的毒、燃烧等持续效果击杀：+5。
- 技能伤害和技能击杀：不产生能量。
- 普通命中、水晶普通命中：不产生能量。
- 合成只有在最终结果高于合成开始前棋盘最高等级时获得能量：`6 ×（参与合成数量 - 1）`。
- 普通合成、没有刷新最高等级的合成不产生能量。

能量在事件发生时立即记录；光点飞抵 HUD 后数值追赶。满能量选择等待最后一组光点抵达。

## 5. 待附着队列

棋盘卡不覆盖已有待附着卡，而是进入队列。下一次合成消耗队首并附着到结果块；多个待附着卡可以跨多次合成依次使用。

带品质的印记随方块移动、下落和重排保留。印记触发时消耗当前品质，并按目标块优先、其他参与块顺序执行。

## 6. 同时触发顺序

如果节点奖励与能量选择同时可用：

```text
节点水晶/统一卡牌选择
→ 能量统一卡牌选择
→ 继续下一波
```

第20波不再进入下一波，而是进入本关结算。
