# 待讨论问题 / Open Questions

## 已从开放问题转为当前事实 / Resolved In Current Build

- 目标平台当前按移动端竖屏和 Web 冒烟优先处理。
- 紫色属性已确定为 Critical：即时 2 倍暴击，不施加持续状态。
- 水晶第一版当前采用 1.8 秒间隔、30% 历史最高等级基础攻击力、单目标、不可暴击。
- 水晶塔默认普通攻击确定为无属性；火、冰、毒、雷效果只通过属性附着卡获得。
- 当前最高等级配置为 36，显示为 1-10 后接 A-Z。

下面的问题仍然保留，是因为它们会影响后续平衡或长期功能，不应阻塞当前版本收口。

## 攻击与数值 / Attack And Numbers

- 多目标攻击是完整伤害还是递减伤害？
- 字母阶段 A、B、C、D、E 的基础攻击力如何继续增长？
- 水晶伤害系数第一版取 20%、25%、30% 还是 35%？
- 水晶攻击频率应该是固定，还是随等级提升略微变快？
- 合成攻击是否需要额外叠加历史最高等级加成，还是只交给水晶解决断档？

## 水晶塔卡牌 / Crystal Tower Cards

- 水晶塔使用一个属性槽，还是允许多个属性同时存在？
- 获得不同属性卡时采用替换、共存，还是由玩家选择保留？
- 已拥有的属性卡是否从本局候选池中移除？
- 攻击力、攻速、额外目标和穿透的具体数值与叠加上限是多少？
- 水晶卡品质只改变数值，还是第一版暂时取消品质差异？
- 总卡池扩展到 13 张后，能量奖励与五波节点奖励如何重新分配抽取权重？

## 怪物与波次 / Monsters And Waves

- 每波持续出怪的间隔是多少？
- 小/中/大怪扣除 1/2/3 耐久是否需要后续微调？
- 后续是否加入特殊怪、护盾怪、快速怪、分裂怪？

## 颜色与属性 / Colors And Elements

- 字母阶段是否继续使用四大基础属性循环？
- 颜色分别对应哪些完整攻击表现？
- 火焰和毒都属于持续伤害，数值和表现如何区分？
- 冰冻是完全停止，还是大幅减速？
- 暴击概率基础 0.25 是否需要后续根据实际战斗节奏微调？
- 雷电连锁是否递减伤害？

## 等级与成长 / Levels And Growth

- 10 之后的字母等级如何命名和显示？
- 字母阶段是否只到 Z，还是 Z 后继续 AA、AB？
- 达到当前最高等级后是否继续扩展到 AA、AB 等复合字母阶段？

## 失败与复活 / Failure And Revive

- 棋盘无可合并是否仍然立刻失败？
- 城堡耐久归零和棋盘无解同时发生时如何结算？
- 游戏结束是否仍然保留原有复活机制？
- 是否存在回血道具或城堡修复道具？

## 道具与技能 / Items And Skills

- 自动触发的小道具和主动释放的大技能如何区分？
- 小道具的自动触发条件是什么？
- 大技能的获得方式和释放入口是什么？
- 道具是否占用棋盘格？
- 道具是否通过合成、击杀、关卡奖励、金币或广告获得？

## 平台与商业化 / Platform And Monetization

- 游戏主要面向移动端还是桌面端？
- 是否需要横屏/竖屏固定？
- 是否要加入广告复活、金币、道具购买等商业化设计？
- 是否需要排行榜、成就系统？
- 是否需要多语言，还是只保留中文/英文其中一种？

## UI 与资源 / UI And Assets

- 是否需要重新设计 UI，还是尽量保持原素材风格？
- 当前 `CONTINUE` 文本按钮是否需要替换成图片按钮？
- 主菜单、加载页、棋盘界面是否继续沿用原素材？
- 静音按钮是否需要区分音乐和音效？
