# 整盘评分动态刷新实验（2026-07-22）

## 算法

动态版以 V2 基础概率为先验。每次补块前，分别虚拟放入全部允许数字，并对放置后的整盘计算：

- 恰好两块成组奖励。
- 减少孤立方块奖励。
- 补齐接近当前最高数字的合成链奖励。
- 增加可合成组奖励。
- 四块以上大组惩罚。
- 单一数字占比过高惩罚。
- 增加棋盘碎片惩罚。
- 最后一格避免死盘奖励或死盘惩罚。

评分通过 `基础概率 × exp(评分 / 2)` 转换为权重，允许数字的最终概率限制在 `3%～55%`，随后重新归一化。算法只用于模拟器，没有修改正式游戏。

## 结论

- 整盘评分明显优于简单邻格加权。清低阶策略不再被锁在数字 5，最高数字 P50 保持 6，停滞率从 57% 降到 4%。
- 优先高阶达到数字 8 的比例从 9% 提高到 84%，失败波次 P50 从 3 推迟到 5，但最终仍全部停滞。
- 随机策略停滞率从 100% 降到 85%，未达到原定 80% 门槛，但失败波次和高阶到达率显著提升。
- `55%` 单数字概率上限意味着：当最后一个空位只有一种数字可以避免死盘时，每次仍至少有 45% 概率失败。长期重复后，优先高阶策略最终停滞接近必然。继续只调评分系数无法解决这个数学边界。
- 本轮暂不运行 12000 局。下一步应单独测试“整盘评分 + 补块后死盘时完整重抽一次”，而不是继续放大普通动态概率。
