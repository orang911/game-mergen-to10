# 核心合成规则 / Core Merge Rules

## 棋盘 / Board

- 当前尺寸：5x5。
- 方块显示尺寸：`132x132`。
- 棋盘坐标使用 `Vector2i(x, y)`。
- 当前显示位置中，`y = 0` 是底部行。

## 方块选择 / Block Selection

- 玩家点击一个方块后，会递归选择上下左右相邻的同等级方块。
- 只有同等级且相邻的方块会被选中。
- 如果只选中 1 个方块，则取消选中并播放抖动反馈。
- 10 级及以上方块当前不能继续被选中合并。

## 合并 / Merge

- 玩家再次点击已选中的目标方块进行合并。
- 被合并方块向目标方块移动并消失。
- 目标方块等级 +1。
- 分数根据合并数量和旧等级计算。
- 合并完成后触发下落和补充。

## 下落与补充 / Fall And Fill

- 每一列从底部向上压实。
- 空位补充随机新方块。
- 初期新方块等级范围是 1-3。
- 当前最高等级超过 4 后，新方块等级范围是 1-4。

## 失败判定 / Failure Check

- 如果棋盘上没有任何上下左右相邻的同等级方块，则游戏结束。
- 10 级及以上方块不参与可合并判定。

## 复活 / Continue And Revive

- 当前复活方式：清除棋盘上最低等级的所有方块。
- 清除后执行下落和补充。
- 如果仍然无可合并方块，会再次进入失败状态。

## 后续注意 / Future Notes

打怪版本会引入城堡耐久失败来源。后续需要确认：

- “棋盘无可合并”是否仍然立刻失败。
- 是否给玩家一次刷新、道具或复活机会。
- 城堡耐久归零和棋盘无解同时发生时，结算优先级如何处理。
