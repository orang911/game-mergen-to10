# 第一章界面美术需求清单

版本：2026-08-12  
适用范围：首次进入、第一章 `1-1` 至 `1-5`、第一章完成后的续战入口、失败与复活。  
产品基线：`00_current_product_baseline.md`

> 本文交付给“数字塔防游戏美术设计师”。目标是把当前可玩的第一章包装成一套完整、统一、可读的竖屏体验；不为尚未实现的商城、任务、签到、广告或永久养成制作正式入口。

## 1. 视觉目标与约束

### 1.1 玩家应在每个界面立即知道的事

| 场景 | 玩家必须在 2 秒内理解 |
|---|---|
| 战斗 | 我正在守护水晶；当前在第几段；下一步可做什么。 |
| 教学 | 现在点击哪里；点击后会发生什么。 |
| 印记选择 | 选哪个；它会在下一次合成时释放。 |
| Boss / 强化 | Boss 是当前首要目标；水晶强化能帮助我赢。 |
| 失败 | 为什么失败；首要行动是复活继续还是重试。 |
| 章节完成 | 第一章已结束；可继续挑战或返回大厅。 |

### 1.2 统一视觉语言

- 画布：竖屏 `941 × 1672`；顶部 HUD、棋盘和底部操作区均保留安全区。
- 风格：圆润 Q 版、魔法蒸汽城堡、低侵略性的金属边框与晶体高光；拒绝写实、硬边、不同 AI 风格混用。
- 层级：教学提示 < 危机提示 < 奖励/决策 < 失败结算，遮罩透明度建议分别为 `35% / 短促闪屏 / 70% / 80%`。
- 主按钮只用一种高亮、饱和的行动色；次按钮用描边或低饱和填充；未实现入口不得伪装为可点击主按钮。
- 玩家文案只表达玩法与下一步，不出现“调参、测试、保留、开发、数值验证”等内部词。

## 2. 当前应移除或降级的假内容

以下内容当前不是可用系统，不能继续以高亮可点击入口出现在第一章版本：

| 现有内容 | 处理要求 |
|---|---|
| 大厅的任务、签到、双倍金币、去广告、首充礼包、存钱罐、商城、货币加号 | 从当前战斗入口大厅隐藏；如保留背景装饰，必须不可点击、不可带红点。 |
| 战斗顶部的货币与大额金币 | 从第一章战斗 HUD 移除或降为纯装饰，不与水晶耐久竞争注意力。 |
| 底部“即时道具”的空槽、无限符号与未实装道具 | 当前版本隐藏；不得留下看似可用却无法理解的槽位。 |
| 失败页中的奖励宝箱、完整伤害构成与卡组标签 | 从失败第一屏移出，改为玩家主动离局后的二级结算。 |

## 3. P0：必须先制作的界面与状态

### 01. 自动 Loading 与清档确认

**目的**：表达“正在进入游戏”，不要求玩家点击开始。  
**必须信息**：Loading 百分比、`正在加载…`、左下角低强调 `清空本地数据`。  
**构图**：沿用水晶/怪物主视觉；进度条位于下部安全区中央；清档为小型文字按钮，不与进度条抢层级。  
**补充状态**：清档二次确认（说明会删除章节、新手、局内进度；`确认清空` 为危险主按钮，`取消` 为次按钮）。

### 02. 精简战斗入口大厅

**目的**：老用户一眼找到唯一可用的战斗入口。  
**必须信息**：主按钮根据状态显示 `开始第一章` / `继续 1-3` / `继续续战 06`；可选副文本显示当前进度。  
**构图**：保留森林岛与水晶世界观；画面中心唯一主按钮；设置为唯一可用次入口。  
**不做**：商城、签到、任务、广告、付费、货币购买入口。

### 03. 常规战斗 HUD

**目的**：在不遮挡棋盘的前提下建立“守护水晶”的核心认知。  
**必须信息**：当前节点（`1-1` 至 `1-5` 或 `续战 01–20`）、水晶耐久 `当前/最大`、暂停入口。  
**推荐构图**：

- 顶部中央：节点标识；常规时显示 `1-3`，不再只写“第 X 波”。
- 水晶附近：清晰的耐久数字与短血条，受伤时红色跳字与震动；这是战斗第一优先级信息。
- 顶部右侧：常规阶段不放货币；Boss 阶段让位给 Boss 徽记/血条。
- 计时是低优先级，可缩小或不显示；不是第一章核心目标。

### 04. Boss HUD 与 Boss 登场提示

**目的**：让玩家知道“需要优先集火的目标出现了”。  
**必须信息**：小 Boss / 大 Boss 徽记、名称占位、生命条、剩余生命；小 Boss 与大 Boss视觉级别不同。  
**表现**：登场时 0.6–0.8 秒横向警示条或徽记落下，随后收束成顶部 Boss 血条；不得用长时间遮挡棋盘的弹窗。  
**可用占位名称**：`方盾哥布林`、`铁甲小僵尸`，后续可按怪物正式命名替换。

### 05. 底部能量与待触发印记 HUD

**目的**：解决“能量满了之后我得到了什么、何时释放”的理解缺口。  
**状态至少包括**：

| 状态 | 必备表现 |
|---|---|
| 未满能量 | 能量进度与简短说明，不出现旧“即时道具”区。 |
| 能量已满待选择 | 明确高亮与短文案 `能量已满，选择印记`。 |
| 已选择印记 | 大图标、印记名、单行效果、固定标签 `下一次合成释放`。 |
| 印记触发 | 图标从 HUD 飞向本次合成结果，HUD 槽位清空。 |

**当前规则**：仅一个待触发印记槽；不可设计成卡牌队列或棋盘附着标记。

### 06. 首次合成教学

**目的**：让新用户理解一键操作。  
**必须文案**：标题 `合成相同数字`；指令 `点击高亮的一组相同数字`；补充 `合成后会攻击最前方怪物`。  
**构图**：棋盘外压暗，高亮同组方块、合流方向和单个手指提示；文字卡不压住高亮格、最前怪或水晶。  
**禁止**：出现“点击两次”“再次点击确认”“拖动 3 个数字”等旧规则文案。

### 07. 水晶受击、晶核与水晶苏醒

该段是三个连续但不同语气的界面状态：

| 状态 | 核心信息 | 表现要求 |
|---|---|---|
| 首次受击 | `水晶受损！怪物触碰水晶会消耗耐久` | 短促红闪、水晶震动、`18/20` 耐久跳字；提示 1.2–1.8 秒后消失。 |
| 获得晶核 | `获得晶核` / `唤醒水晶，解锁持续攻击` | 晶核卡与水晶形成清晰飞行路径；卡不遮挡水晶。 |
| 已苏醒 | `水晶已苏醒，会自动攻击最前方怪物` | 非阻断的短提示条，约 2 秒淡出；水晶发光与首次攻击同步。 |

### 08. 印记选择弹窗

**用途**：`1-3` 的固定锻锤教学和锻锤/魔炮二选一；后续满能量随机选择复用同一结构。  
**当前第一章要求**：两张卡，无广告锁定、无第三张占位。  
**必备信息层级**：卡名 → 一次效果 → `下一次合成立即释放` → 选中效果预览 → 确认。  
**状态交付**：未选、悬停/按下、已选（高亮+勾选）、确认按钮禁用（`请选择一枚印记`）、确认按钮可用（`确认选择`）。  
**版式原则**：选择卡不等于立即释放，必须用一句话解释延后触发；背景战场可见但降暗。

### 09. 节点轻过场

**用途**：完成 `1-1`、`1-2`、`1-3` 后确认进度继承。  
**必须信息**：`1-1 完成`、`下一节点 1-2`、水晶耐久/棋盘/能量三个继承图标、主按钮 `继续`。  
**构图**：屏幕中部约 22–28% 高度的小面板；战场背景仍可辨认；不使用胜利结算、宝箱或长表格。

### 10. 小 Boss 后水晶强化

**目的**：让玩家明确强化用于挑战大 Boss。  
**流程画面**：击败小 Boss → `星核蒸汽炉`卡牌出现 → 卡牌飞入水晶 → 水晶亮起 → `水晶攻击 +10%`。  
**必备主按钮**：`挑战大 Boss`。  
**局内常驻状态**：强化完成后，在水晶附近或底部水晶状态区显示小型“星核蒸汽炉 +10%”标记，直到本局结束。

### 11. 第一章节算与续战入口

**目的**：表现大 Boss 被击败与第一章完成，而非展示开发信息。  
**必备信息**：`第一章完成`、胜利徽记/水晶点亮、大 Boss 击败反馈、主按钮 `继续挑战`、次按钮 `返回大厅`。  
**玩家文案**：`前方出现新的怪潮，是否继续守护水晶？`  
**禁止**：出现“保留的 20 波”“数值”“后续开发”等内部文案。  
**后续 HUD**：进入后显示 `续战 01` 至 `续战 20`。

### 12. 失败、复活与离局结算

**必须拆为三页，不做旧版大表格失败页。**

| 页面 | 必备内容 | 按钮优先级 |
|---|---|---|
| 失败抉择 | `水晶破碎`、失败原因、到达节点 | 主：`复活继续`；次：`重新开始`；低强调：`返回大厅`。 |
| 复活反馈 | 水晶耐久恢复、棋盘/章节状态的恢复说明、回到战斗短动画 | 不再出现第二次选择。 |
| 离局结算 | 最高数字、击杀、合成次数、坚持节点/波次 4 项 | `再来一局` 或 `返回大厅`。卡组/伤害构成进入二级查看。 |

## 4. P1：第一章稳定后补齐

- 暂停菜单：继续战斗、设置、返回大厅；不显示未实现系统。
- 设置页：音效、音乐、震动、帮助、清档入口。
- 续战结算：与章节结算区分为“守护记录/最高续战波次”，不伪装成第二章完成。
- 卡牌图鉴或本局强化面板：只在水晶卡数量与玩法稳定后制作。

## 5. 美术交付物与验收

### 5.1 首轮交付：12 套界面效果图

1. Loading（含清档确认状态）
2. 精简大厅
3. 常规战斗 HUD
4. Boss HUD/登场
5. 底部能量与待触发印记（四态同页）
6. 首次合成教学
7. 水晶受击/晶核/苏醒（三态同页）
8. 印记选择（四态同页）
9. 节点轻过场
10. 小 Boss 后水晶强化
11. 第一章节算/续战入口
12. 失败、复活、离局结算（三页组图）

每套至少提供：默认状态、主操作状态、出现/退出或关键动画分镜；所有主按钮提供默认、按下、禁用三态。

### 5.2 验收清单

- 每个页面在 2 秒内只表达一个最高优先级目标与一个主操作。
- 所有信息不遮挡棋盘可操作格、水晶耐久、最前怪物或 Boss 血条。
- 同一类按钮、边框、字体描边、晶体高光、遮罩层级在所有页面统一。
- 当前未实现的商城、广告、签到、任务、购买、即时道具不产生可交互或高亮入口。
- 所有文本符合一键合成规则与“下一次合成释放印记”规则。

## 6. 2026-08-13 补充：暂停、设置与大厅成长/商业化界面

> 本节为最新需求，覆盖第 2 节中“任务、签到、商城等暂时隐藏”的限制。第一章战斗主流程仍不放置这些入口；它们仅在大厅中出现，并与“开始/继续战斗”主按钮保持明确的层级差。

### 13. 战斗暂停菜单

**触发与恢复**：点击战斗 HUD 的暂停图标进入；再次点击暂停图标、点击面板外的暗色区域或系统返回操作均恢复战斗。恢复不单独做第三个大按钮。

**画面要求**：

- 暂停时立刻冻结战斗逻辑与画面关键帧；战场完整保留但叠加 `65–70%` 深蓝黑遮罩，保证玩家仍能看清水晶、Boss 与棋盘轮廓。
- 屏幕中部使用小型圆角悬浮面板，标题为 `暂停中`；不展示波次统计、卡牌、广告或货币。
- 面板仅有两个等宽操作：`设置`（次按钮，齿轮图标）与 `退出`（低饱和红色危险按钮，离开本局并返回大厅）。
- `退出`按下态须明显；如需要二次确认，使用同一位置的轻量确认层，不新增常驻第三按钮。确认文案：`退出后将结束本次挑战`；按钮：`继续挑战` / `确认退出`。

**美术交付状态**：暂停出现前 → 深色遮罩/菜单出现 → 设置按下 → 退出确认，共 4 帧。不得以模糊遮住全部战场，也不能把暂停菜单设计成失败结算。

### 14. 大厅设置页

**入口与目的**：大厅右上角齿轮进入；用于基础偏好与账号/数据操作，不承担付费和活动入口。

**信息架构**：

| 分区 | 项目 | 视觉/交互要求 |
|---|---|---|
| 声音 | 音乐、音效、震动 | 三个独立开关；开关状态需清晰且可单手操作。 |
| 支持 | 帮助与反馈、隐私/用户协议 | 使用低强调列表行，不抢夺声音设置的注意力。 |
| 数据 | 清空本地数据 | 固定在最下方，红色文字按钮；复用 Loading 页的二次确认样式。 |

**版式**：全屏浅色内容面板或居中大面板均可；顶部只保留返回与标题 `设置`。不展示签到、任务、商城、礼包或货币。

### 15. 大厅成长入口总览

**目的**：让老用户从大厅识别“可做的日常事”和“可购买的内容”，同时确保最高优先级永远是 `开始/继续战斗`。

**大厅层级**：

1. 中央/底部最大主按钮：`开始战斗`、`继续 1-3` 或 `继续挑战`。
2. 顶部：头像/设置，以及简洁的货币展示；货币数量必须有文字或图标辨识，不使用小号装饰数字。
3. 侧边或底部的二级功能区：`任务`、`签到`、`商城`。仅当相关功能可用时显示红点；不可用时不以“待领取”红点误导。
4. 限时或付费内容使用一张活动卡位轮播：`首充礼包`、`存钱罐`、`双倍金币`。同屏只突出一张，不得同时堆叠三张大促销横幅。

**统一规范**：任务/签到采用蓝绿或金色的成长感；商城/礼包采用金橙色但不超过战斗主按钮的视觉权重；所有入口使用圆润 Q 版、魔法蒸汽水晶材质与短文案。

### 16. 任务与签到

**建议合并为一个“日常”页面，顶部 Tab 为 `任务` / `签到`，减少大厅入口数量。**

| 页面 | 必须内容 | 关键状态与交互 |
|---|---|---|
| 日常任务 | 今日进度、3–5 条短任务、每条奖励图标与数量 | 未完成、进行中、可领取、已领取；可领取只高亮对应的 `领取`，不提供误导性的“一键全部完成”。 |
| 每日签到 | 7 天连续格、当天奖励、连续天数 | 当天可领取时仅当天卡位高亮；补签、双倍领取等功能只在实际实现后增加，不能以广告占位。 |
| 领取反馈 | 奖励飞向顶部货币栏/背包的短动画 | 反馈 `0.5–0.8 秒`；不弹成长表格或打断玩家返回大厅。 |

**文案示例**：`完成 1 次挑战`、`合成 20 次`、`击败 30 个怪物`、`今日签到`。任务来源于实际可统计行为，避免“观看广告”等当前不可用任务。

### 17. 双倍金币与去广告

**定位**：一个权益页，而非大厅常驻弹窗。大厅只允许通过小型活动卡进入。

**画面层级**：权益主视觉（金币/水晶/小怪） → 明确权益卡 → 价格与购买按钮 → 权益说明/恢复购买。

| 权益 | 必须说明 | 视觉要求 |
|---|---|---|
| 双倍金币 | `挑战结算金币 +100%`、生效范围、是否永久/时限 | 金币翻倍的前后对比，避免夸张的“无限收益”暗示。 |
| 去广告 | `移除非主动广告`、保留/不保留奖励广告的规则 | 使用安静的盾牌/禁广告图标，不要把广告角色做成主视觉。 |

**购买状态**：默认、购买中、购买成功、已拥有、购买失败、恢复购买；已拥有时主按钮替换为不可点击的 `已拥有`，不再显示价格。

### 18. 首充礼包

**目的**：用一次明确的首购奖励促成转化，不能与多个礼包争夺焦点。**

- 大厅入口使用单张小卡；未购买时可带一次轻量呼吸高光，已购买后入口完全移除。
- 礼包页必须展示：礼包名、价格、3–4 项实际奖励、`首次购买限定`、购买按钮与奖励预览。
- 奖励用“水晶卡、印记、货币”的实际图标组合展示；没有实现的角色/皮肤不得放入奖励。
- 购买成功后，按“宝箱打开 → 奖励逐个飞入对应位置 → 返回大厅”表现；整段控制在 2 秒左右，并可跳过。

### 19. 存钱罐

**目的**：把挑战中累计的额外货币转化为一次可理解、可预期的购买。**

**核心画面**：大厅显示小型透明水晶罐，不要遮挡战斗主按钮；点击进入详情。

| 状态 | 必须表现 |
|---|---|
| 未积累 | 空罐/低亮，说明“挑战可积累晶币”。 |

### 20. 商城

**入口**：大厅二级功能区的 `商城`；进入后保留返回大厅，不从商城直接切到战斗。

**信息架构**：顶部货币栏 → 分类 Tab（`推荐` / `货币` / `水晶卡` / `印记`；仅展示已实现分类） → 商品列表 → 商品详情/购买确认。

**单个商品卡规范**：图标、名称、数量/效果、价格、限购/剩余次数（若真实存在）；卡面在 2 秒内能区分“买什么、花什么”。每页优先展示 4–6 项，不能把所有商品压成密集表格。

**必做状态**：默认、缺货、限购已达上限、货币不足、购买确认、购买成功；货币不足的主按钮显示所缺货币并导向合法获得路径，不自动跳转广告。
