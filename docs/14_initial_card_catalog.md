## 棋盘卡

这五张卡进入待附着队列，在后续合成结果块上生成技能印记。

1. **晶核跃升** `core_ascension`：基础 +1 级，稀有品质 +2 级。
2. **同频汇聚** `frequency_convergence`：保留结果块和最高等级块，其余方块向最低等级统一；品质提高统一等级。
3. **碎片重铸** `fragment_reforge`：所有最低等级方块升级；品质决定升级幅度。
4. **棋盘回响** `board_echo`：重排等级与印记，并保证至少存在一组可合成方块。
5. **寒星冲击** `frost_star`：攻击最靠近城堡的目标；品质提高目标数、伤害、减速和持续时间。技能击杀不产生能量。

## 水晶卡

这四张卡在卡牌飞抵水晶塔后立即应用，效果持续当前游戏对局或指定波数。

1. **星核增幅** `star_core`：水晶攻击力 +15% / +25% / +35%。
2. **迅流脉冲** `rapid_pulse`：攻击间隔乘以 0.90 / 0.82 / 0.75。
3. **元素棱镜** `element_prism`：火、冰、毒、雷四选一，持续 1 / 2 / 3 波。
4. **双重折射** `double_refraction`：额外命中 +1 / +1 / +2 个目标。

## 抽取规则

### 能量满

- 三选一。
- 两张棋盘卡 + 一张总卡池卡。
- 普通品质为主，少量优秀，稀有低概率出现。

### 五波节点

- 第5、10、15、20波开始前各一次三选一。
- 两张水晶卡 + 一张总卡池卡。
- 至少一张稀有水晶卡，不出现普通品质。
