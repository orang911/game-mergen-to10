# 战斗系统设计 / Combat Design

更新：2026-08-06
上位规则：`00_current_product_baseline.md`
数值来源：`26_combat_balance_master.md` 与 `scripts/game_config.gd`

## 战斗目标

玩家守护“水晶城堡”。怪物沿棋盘外圈路径行进，抵达水晶边界即造成耐久伤害并消失。水晶耐久初始为 20；耐久归零即失败。

合成攻击是主动爆发，水晶普通攻击是低频保底输出。两者都优先攻击当前最靠近水晶的怪物。

## 怪物与波次

- 普通怪分为小、中、大三种，基础生命、速度、体型和耐久伤害配置在 `GameConfig.MONSTER_CONFIG`。
- 第一章使用明确配置的波次与出怪顺序，而非公式生成。
- 常规出怪间隔在第一章为 0.86–1.00 秒；怪物数量和血量随节点递增。
- Boss 波为 Boss 先出、护卫后出，使集火目标清晰。
- 小 Boss：120 HP、耐久伤害 2、强化方盾哥布林表现；大 Boss：300 HP、耐久伤害 3、强化铁甲小僵尸表现。
- Boss 第一版只增加外观、尺寸、血条和 HUD 标记，不引入专属 AI、多阶段或主动技能。

## 第一章战斗节奏

```text
1-1：水晶苏醒与基础合成
1-2：小中怪递增，观察属性反馈
1-3：印记教学与一次自主使用
1-4：护卫 → 小 Boss → 固定水晶强化
1-5：大 Boss → 第一章节算 → 可选续战
```

第一章以连续战斗为单位，节点切换只展示轻量过场，不清空棋盘、不重置耐久、不清空能量或强化。

## 五属性反馈

| 属性 | 伤害与控制 | 关键表现 |
|---|---|---|
| 毒 | 最多 4 层，每秒结算全部层的合计伤害 | 红闪与一次合计红色减血飘字。 |
| 冰冻 | 移速固定为原速 40%，持续 2 秒 | 怪物蓝色化，移动明显减慢。 |
| 闪电 | 主目标与链路按顺序受击 | 命中时抬高、抖动、硬直约 1 秒。 |
| 暴击 | 暴击倍率与随阶增长的普通怪湮灭 | 紫白爆闪与湮灭提示；Boss、教学保护怪免疫湮灭。 |
| 火焰 | 最多 4 层燃烧，并保留范围溅射 | 叠层燃烧状态与范围受击。 |

所有直接命中会短暂停顿怪物路径移动；毒和燃烧的持续结算不施加额外停顿。

## 20 波续战

第一章完成后保留 20 波公式续战，用于测试高压下的输出、补给、属性与水晶强度。它不替代第一章，也不承担第二章叙事或正式解锁内容。
