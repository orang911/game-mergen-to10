# 战斗系统设计 / Combat System Design

## 核心方向 / Core Direction

目标是在原有数字合成玩法上加入打怪系统，让棋盘合成转化为攻击、防守和生存压力。

- 棋盘仍位于画面中心。
- 玩家继续通过合成数字元素进行操作。
- 数字和字母代表攻击成长阶段。
- 怪物以队列形式围绕棋盘行进。
- 玩家通过合成产生攻击，阻挡或消灭怪物。
- 怪物到达终点时扣除城堡耐久。
- 游戏目标从单纯追求高分，扩展为持续合成、持续防守和生存更久。

## 怪物队列 / Monster Queue

- 怪物沿固定路径移动。
- 路径采用完整环绕棋盘的形式。
- 怪物从左上角进入。
- 终点设置在入口旁边，接近绕满一圈但不与入口完全重合。
- 怪物按队列依次出现。
- 怪物生成采用“波次 + 持续混合”的节奏。
- 第一版只做普通怪，先跑通系统。
- 怪物外观方向采用抽象几何怪。
- 怪物到达终点后扣除城堡耐久并消失。
- 城堡耐久归零后进入失败结算。

## 普通怪数值 / Normal Monster Stats

第一版普通怪只用大小区分强度。

| 怪物大小 | 血量 | 到达终点扣除耐久 |
| --- | --- | --- |
| 小怪 | 5 | 1 |
| 中怪 | 12 | 2 |
| 大怪 | 25 | 3 |

## 波次规则 / Wave Rules

- 第一版波次主题按数量和大小变化推进。
- 越往后怪物越密集，中/大怪比例越高。
- 每波结束条件：该波怪物全部生成完，并且场上怪物清空。

第一版波次配置建议：

```gdscript
const WAVES := [
	{"small": 6, "medium": 0, "large": 0, "spawn_interval": 1.0},
	{"small": 8, "medium": 2, "large": 0, "spawn_interval": 0.9},
	{"small": 10, "medium": 4, "large": 1, "spawn_interval": 0.8},
]
```

## 城堡耐久 / Castle Durability

- 玩家生命表现为“城堡耐久”。
- 初始城堡耐久为 20，整体偏休闲。
- 怪物按大小扣除不同耐久，例如 1/2/3。
- 城堡耐久归零后游戏结束。

## 颜色属性 / Color Elements

目标：等级负责攻击力成长，颜色负责攻击属性区分。

| 颜色 | 属性 | 效果方向 |
| --- | --- | --- |
| 红色 | 火焰 | 持续伤害 |
| 蓝色 | 冰冻 | 停止怪物 |
| 黄色 | 雷电 | 连锁攻击 |
| 绿色 | 毒 | 持续伤害 |

当前 1-10 素材颜色归并：

| 等级 | 当前颜色观察 | 属性倾向 |
| --- | --- | --- |
| 1 | 亮绿色 | 毒 |
| 2 | 青蓝色 | 冰冻 |
| 3 | 金黄/橙黄 | 雷电 |
| 4 | 橙色 | 火焰 |
| 5 | 红色 | 火焰 |
| 6 | 绿色 | 毒 |
| 7 | 蓝色 | 冰冻 |
| 8 | 紫色 | 毒 |
| 9 | 紫红色 | 雷电 |
| 10 | 黄色 | 雷电 |

第一版只保留火焰、冰冻、雷电、毒四大基础属性。青蓝、橙、紫、紫红等颜色暂时归并，不单独设计新属性。
