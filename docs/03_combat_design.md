# 战斗系统设计 / Combat System Design

## 核心方向 / Core Direction

目标是在原有数字合成玩法上加入打怪系统，让棋盘合成转化为攻击、防守和生存压力。

- 棋盘仍位于画面中心。
- 玩家继续通过合成数字元素进行操作。
- 数字和字母代表攻击成长阶段。
- 怪物以队列形式围绕棋盘行进。
- 玩家通过合成产生攻击，阻挡或消灭怪物。
- 怪物到达终点时扣除城堡耐久。
- 游戏目标从单纯追求高分，扩展为持续合成、持续防守和生存更久。

## 怪物队列 / Monster Queue

- 怪物沿固定路径移动。
- 路径采用完整环绕棋盘的形式。
- 怪物从左上角进入。
- 终点设置在入口旁边，接近绕满一圈但不与入口完全重合。
- 怪物按队列依次出现。
- 怪物生成采用“波次 + 持续混合”的节奏。
- 第一版只做普通怪，先跑通系统。
- 怪物外观方向采用抽象几何怪。
- 怪物到达终点后扣除城堡耐久并消失。
- 城堡耐久归零后进入失败结算。

## 普通怪数值 / Normal Monster Stats

第一版普通怪只用大小区分强度。

| 怪物大小 | 血量 | 到达终点扣除耐久 |
| --- | --- | --- |
| 小怪 | 5 | 1 |
| 中怪 | 12 | 2 |
| 大怪 | 25 | 3 |

## 波次规则 / Wave Rules

- 当前关卡固定 20 波，怪物总数从第一波 15 只线性增长到第二十波 60 只。
- 中间波次按相同进度均匀递增；任何单波总数不得超过 60。
- 越往后中/大怪比例越高，但小/中/大型怪物之和必须等于该波目标总数。
- 每波结束条件：该波怪物全部生成完，并且场上怪物清空。

第一版波次配置建议：

```gdscript
const WAVES := [
	{"small": 6, "medium": 0, "large": 0, "spawn_interval": 1.0},
	{"small": 8, "medium": 2, "large": 0, "spawn_interval": 0.9},
	{"small": 10, "medium": 4, "large": 1, "spawn_interval": 0.8},
]
```

## 城堡耐久 / Castle Durability

- 玩家生命表现为“城堡耐久”。
- 初始城堡耐久为 20，整体偏休闲。
- 怪物按大小扣除不同耐久，例如 1/2/3。
- 城堡耐久归零后游戏结束。

## 颜色属性 / Color Elements

方块颜色与运行属性固定一一对应，按等级循环：

```text
绿色毒 → 蓝色冰冻 → 黄色闪电 → 紫色暴击 → 红色火焰……
```

- 毒：每发命中刷新持续时间，毒伤以该发伤害计算。
- 冰冻：合并 `N` 个方块锁定前方 `N-1` 个不同目标，每个目标承受一次完整基础伤害并刷新减速；弹道按 `0.10秒` 错落发射。
- 闪电：只产生一次主攻击；额外合并方块提高主攻击伤害、弹跳次数和弹跳保留率，随后按前后顺序逐段弹射并衰减。
- 暴击：每发独立判定，只放大当前一发伤害。
- 火焰：每发施加燃烧并保留溅射，燃烧与溅射均以该发伤害计算。
- 冰冻与闪电恢复进入方块合成循环、提示、弹道、受击和模拟器；冰雷四张历史卡仍不进入当前随机卡池。

## 连续集火规则 / Sequential Focus Fire

- 此规则只作用于毒、暴击和火焰；冰冻与闪电使用上方的独立目标规则。
- 合并 `N` 个方块产生 `N` 发，而不是预先选取多个目标同时齐射。
- 单个序列持续攻击当前最靠近水晶的怪物；该怪存活时不因其他怪物位置变化而换目标。
- 目标在弹道飞行中死亡或到达水晶时，弹道和结算改锁当时新的最前怪物。
- 命中后等待 `0.05秒` 再发下一发；不同合成产生的序列互不合并，可交错执行。
- 重开、返回主页或进入结算时取消全部未完成序列和弹道。

毒、暴击、火焰伤害公式：`总伤害 = B × max(1, N - 1)`，`单发伤害 = 总伤害 ÷ N`。

冰冻伤害公式：`目标数 = max(1, N - 1)`，`每目标伤害 = B`。闪电主伤害与弹跳参数由 `GameConfig.calculate_attack_damage()`、`calculate_lightning_bounces()` 和 `calculate_lightning_retention()` 统一计算。

## 合成攻击提示 / Merge Attack Prompt

每次合成成功后显示一条行内横幅提示，无论是否有怪物目标。

- 横幅元素使用 source_level 对应的 event.element_key。
- 显示事件的 `total_damage` 与 `attack_count`；冰冻显示实际目标发数，闪电显示一次主攻击，毒/暴击/火焰显示连续发数。
- 暴击、连锁、溅射、毒/燃烧 tick 不改变横幅显示的攻击数值。
- 行的位置对应合成后存活的结果方块所在行（result block row）。
- 无目标时同样显示横幅，不跳过。
