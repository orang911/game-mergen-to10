# 当前项目状态 / Current State

更新：2026-08-06
产品基线：`00_current_product_baseline.md`

## 已完成且正在使用

- 5×5 数字合成棋盘、下落补充、等级 1–10 与 A–Z 显示。
- 水晶城堡、防守路径、小/中/大怪、怪物血条、波次、耐久和失败结算。
- 五色合成攻击、弹道、命中、毒/火叠层、冰冻、闪电硬直与链路、暴击和普通怪湮灭。
- 第一章 5 节点 12 波，小 Boss 固定水晶强化、大 Boss、章节过场和 20 波续战。
- Loading 自动进入、首用户直入教学、老用户大厅、清空本地数据、章节与续战的完整续玩。
- 能量 HUD、满能量选择、下一次有效合成印记、章节印记教学和水晶强化卡。
- 运行时 6 张印记 + 6 张水晶卡，以及对应二级选择弹窗。
- 战斗数值主表和模拟器；当前有章节、Loading、卡牌、战斗、元素、续玩等 smoke 覆盖。

## 当前事实

- 第一章是主线入口；20 波仅作为章节完成后的“续战”数值场。
- 水晶与城堡是同一守护目标，怪物触及水晶边界即攻击并移除。
- 水晶开场暗淡，首波突破怪攻击后苏醒；第一章不启用棋盘合成触发水晶等级成长。
- 印记不再占用棋盘格，也不存在待附着队列；始终只有一个“下一次有效合成”槽位。
- 当前代码卡池为 12 张；旧 9 卡与目标 16 卡均不是当前运行规则。

## 当前研发重点

1. 第一章首局体验：教学可读性、前 3 节点节奏、Boss 目标感与失败感受。
2. 续战数值：怪物血量、出怪节奏、属性输出、水晶补偿和印记获得频率。
3. 二级弹窗与战斗美术：统一 Q 版怪物、Boss 区分、水晶苏醒、印记选择、强化和结算。
4. 移动端真机体验：触控、帧率、加载和存档恢复。

## 暂不纳入本轮

第二章、特殊怪 AI、Boss 技能、永久成长、16 张目标卡池、商业化、排行榜和大规模主流程重构。
