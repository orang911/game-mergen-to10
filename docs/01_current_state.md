## 当前已有玩法 / Existing Gameplay

- 5x5 棋盘。
- 点击相邻同等级方块进行选中。
- 再次点击已选中的方块，将整组选中方块合并到目标方块。
- 合并后目标方块等级 +1。
- 计分公式：`(合并数量 - 1) * 方块等级 * 2`。
- 合并后方块下落，并随机补充新方块。
- 当前最高等级超过 4 后，新方块随机范围提高到 1-4。
- 达到最高等级（当前配置为 36，即 Z）后弹出成功提示，并移除该方块。
- 无可合并方块时进入游戏结束。
- 继续/复活逻辑：清除当前最低等级方块。
- 支持重新开始、返回主菜单、静音、点击音效、合并音效。
- 最高分保存到 `user://merge_to_10.cfg`。
