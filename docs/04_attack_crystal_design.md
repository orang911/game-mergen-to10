# 攻击与持续水晶设计 / Attack And Continuous Crystal Design

## 设计问题：低级合成攻击断档 / Problem: Low-Level Attack Drop-Off

玩家为了持续合成更高等级，后期仍然需要从低等级数字开始合成。

如果攻击只按“当前这一次合成出来的等级”结算，就会出现：

- 玩家明明已经成长到高等级。
- 但大量实际操作仍然是 1、2、3、4 的低级合成。
- 后期怪物压力变高时，低级合成攻击力太低。
- 玩家会感觉“我已经成长了，但大部分操作像没有输出”。

这是合成成长和战斗结算之间的核心矛盾。

## 当前确定方向 / Confirmed Direction

用两层攻击解决：

```text
当前合成攻击 = 主动攻击 / 爆发攻击
持续攻击水晶 = 成长基础攻击 / 保底输出
```

合成攻击仍然是主要操作反馈和爆发来源。持续攻击水晶用于承载玩家本局成长后的基础战力，避免后期低级合成完全断档。

## 当前落地状态 / Implemented Status

- `scripts/crystal_system.gd` 与 `scripts/crystal_view.gd` 已接入 `CombatSystem`。
- 水晶初始为 1 级；原有“棋盘合成结果达到 3、5、7 时提升 1 级”的代码与 1～9 级资源继续保留，但新手/前期版本默认关闭，等待后续长线系统解锁。
- 当前攻击间隔为 1.8 秒，伤害系数为水晶当前等级基础攻击力的 30%，单目标。
- 水晶攻击复用弹道系统；游戏停止、失败或重开时停止并清理计时。
- 当前水晶不触发暴击，属性效果也暂不作为水晶的输出重点。

以上数值目前写在 `scripts/crystal_system.gd`，后续稳定后应迁移到 `GameConfig`，避免配置分散。

## 合成攻击 / Merge Attack

- 攻击以“合成后一次性触发”为核心。
- 每次成功合成时，立刻释放一次攻击。
- 不让棋盘上的普通方块持续自动攻击。
- 一次性攻击优先攻击最靠近终点的怪物。
- 合成数量越多，攻击伤害越高。
- 合成数量越多，攻击目标数量也越多。
- 等级决定基础攻击力，颜色决定攻击属性，合成数量决定本次攻击威力和覆盖范围。

第一版基础攻击力：

| 等级 | 基础攻击力 |
| --- | --- |
| 1 | 2 |
| 2 | 4 |
| 3 | 6 |
| 4 | 10 |
| 5 | 14 |
| 6 | 18 |
| 7 | 25 |
| 8 | 32 |
| 9 | 40 |
| 10 | 50 |

合成数量加成：

- 2 个方块合成是基础伤害。
- 每多合成 1 个方块，伤害增加 20%。
- 目标数 = `合成数量 - 1`。

建议公式：

```gdscript
最终合成伤害 = 当前等级基础伤害 * (1.0 + max(0, 合成数量 - 2) * 0.2)
```

## 持续攻击水晶 / Continuous Attack Crystal

定位：

- 水晶不是主输出塔。
- 水晶是玩家本局成长后的基础战力表现。
- 水晶提供稳定、低频、单目标的保底输出。
- 玩家真正的爆发、多目标和属性策略仍然来自合成攻击。

保留的成长能力（当前默认关闭）：

- 水晶初始等级为 1，最高等级为 9。
- 棋盘合成结果为 3、5、7 时触发水晶升级；其他合成等级不触发。
- 每次满足条件只让水晶提升 1 级，不把水晶等级直接设置为棋盘数字。
- 水晶外观和战斗等级始终按 1、2、3、4、5、6、7、8、9 的顺序变化，偶数级不会跳过。
- 同一个触发等级可以重复生效，例如连续两次合成出 3，可以让水晶从 1 级升到 3 级。
- 当前由 `GameConfig.CRYSTAL_MERGE_UPGRADES_ENABLED = false` 阻止棋盘合成触发；后续系统可通过 `CrystalSystem.set_merge_upgrade_enabled(true)` 重新开启。

攻击规则建议：

| 项目 | 第一版建议 |
| --- | --- |
| 水晶等级 | 初始 1 级；合成出 3、5、7 时每次 +1；最高 9 级 |
| 目标 | 最靠近终点的怪物 |
| 攻击频率 | 每 1.2 到 2.0 秒一次 |
| 单次伤害 | 水晶当前等级基础攻击力的 20% 到 35% |
| 目标数量 | 1 个 |
| 属性 | 可先用当前最高等级颜色属性，或先做无属性普通伤害 |
| 暂停规则 | 游戏暂停、弹窗、失败时暂停 |

示例：

- 水晶当前为 4 级，玩家合成出 5，水晶提升到 5 级。
- 随后玩家合成出 4，水晶仍保持 5 级。
- 再次合成出 3，水晶提升到 6 级并显示 6 级素材。
- 6 级基础攻击力是 18，水晶系数取 0.3 时，每次攻击约 5 点伤害。

## 表现设计 / Visual Presentation

水晶可以作为画面中的成长核心物件：

- 放在棋盘上方、棋盘中心背景、终点附近，或棋盘外圈的固定锚点。
- 等级越高，水晶体积、亮度、脉冲和外圈光环增强。
- 合成高等级时，水晶短暂充能和闪光。
- 水晶攻击时发射细光束或能量弹。
- 达到 A/B/C 后可以增加外圈符文、光环层数或颜色变化。

表现原则：

- 水晶要让玩家看到“本局已经变强”。
- 水晶不能抢走合成攻击的主角位置。
- 水晶攻击节奏要稳定，不要造成过多视觉噪声。

## 技术接口建议 / Technical Interface Suggestions

新增或预留模块：

- `CrystalSystem`：管理水晶等级、攻击计时、目标选择和暂停状态。
- `CrystalView`：管理水晶外观、升级、脉冲、充能表现。
- `CombatSystem`：持有或协调 `CrystalSystem`。
- `ProjectileSystem`：复用水晶弹道和合成攻击弹道。
- `EffectSystem`：播放水晶升级、命中和攻击反馈。

事件关系：

```text
MergeSystem 合成成功
└─ 发出 MergeAttackEvent
   ├─ CombatSystem 处理本次合成攻击
   └─ CrystalSystem 检查合成后等级是否为 3、5、7
      └─ 命中触发等级时，将水晶当前等级提升 1 级
```

第一版可以先只做：

- 合成成功时更新水晶等级。
- 水晶按固定间隔攻击最靠近终点的怪物。
- 使用普通伤害，不接复杂属性。
