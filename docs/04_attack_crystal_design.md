# 水晶城堡与水晶卡 / Crystal Castle And Cards

更新：2026-08-06
上位规则：`00_current_product_baseline.md`

## 唯一守护目标

城堡与水晶塔已合并为同一对象“水晶城堡”。它同时承担：

- 玩家耐久与失败判定；
- 怪物的行进终点；
- 自动普通攻击的发射点；
- 水晶强化卡的安装与表现承载。

怪物触及水晶边界就攻击，不再走入水晶内部。

## 第一章水晶苏醒

- 开场水晶暗淡，不攻击。
- 1-1 的突破怪在水晶边界造成一次固定教学伤害。
- 随后出现提示，水晶苏醒并完成首次反击，建立“守护水晶”的目标认知。
- 苏醒后水晶普通攻击状态会继承至本章节结束与续战。

## 普通攻击

- 初始等级为 1，攻击间隔 1.8 秒。
- 攻击最靠近水晶的怪物；基础伤害为当前水晶等级基础攻击力的 30%。
- 普通攻击不暴击；安装水晶卡后可获得元素附着、伤害、攻速、额外目标或穿透。
- 暂停、选择弹窗、失败和结算期间不继续攻击。

## 当前水晶卡池

| 卡牌 | 当前作用 |
|---|---|
| 炉心龙纹管 | 水晶命中附加燃烧。 |
| 腐蚀炼金罐 | 水晶命中附加毒伤。 |
| 星核蒸汽炉 | 提高水晶普通攻击伤害；第一章小 Boss 后固定给 1 星，效果 `+10%`。 |
| 迅流发条机 | 缩短水晶普通攻击间隔。 |
| 双塔折射镜 | 增加水晶普通攻击的额外目标。 |
| 城墙穿透炮 | 增加穿透与后续目标伤害。 |

卡牌状态仅在当前章节/续战内生效，并随中断续玩保存恢复。
