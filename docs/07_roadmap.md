# 实现路线图 / Implementation Roadmap

> 本路线图描述目标阶段；截至 2026-07-15，阶段 1-3 已完成，阶段 4 基本完成，当前执行重点转为版本收口和阶段 5 反馈打磨。可执行任务以 `12_execution_plan_2026-07-15.md` 为准。

## 阶段 0：结构整理 / Phase 0: Structure Cleanup

目标：

- 不改变现有玩法。
- 先建立配置、事件和系统边界。
- 让后续战斗、弹道、特效、水晶可以接入。

验收：

- 原有合成操作不变。
- 原有成功、失败、复活、重开不变。
- 合成完成后可以生成攻击事件。
- 战斗系统可以接收事件，但暂时不改变表现。

## 阶段 1：战斗最小闭环 / Phase 1: Minimal Combat Loop

目标：

- 新增怪物路径。
- 新增小/中/大普通怪。
- 新增城堡耐久。
- 怪物沿路径移动，到终点扣耐久并消失。
- 波次持续出怪，并按清空场上怪物进入下一波。

验收：

- 进入游戏后，可以看到怪物从左上入口沿棋盘外圈回形路径移动。
- 怪物到达终点后消失，并扣除城堡耐久。
- 小/中/大怪的尺寸、速度、扣耐久不同。
- 波次会按配置持续生成怪物。
- 一波全部生成完且场上清空后，进入下一波。
- 城堡耐久归零后游戏结束。
- 怪物路径不遮挡棋盘点击。
- 重新开始会清空旧怪物、重置波次和城堡耐久。

## 阶段 2：合成攻击接入 / Phase 2: Merge Attack Integration

目标：

- 合成完成后生成攻击事件。
- 按路径进度选择最靠近终点的目标。
- 根据等级和合成数量计算伤害。
- 怪物受伤、死亡、移除。

验收：

- 玩家完成一次合成后，最靠近终点的怪物会受到伤害。
- 合成数量越多，伤害更高，攻击目标更多。
- 小怪血量为 5 时，可以被中高等级攻击明显击杀。
- 怪物死亡后不会继续移动、不会到终点扣耐久、不会被重复选中。
- 没有怪物时合成不会报错。
- 波次系统仍然能正确判断场上清空并进入下一波。

## 阶段 3：持续攻击水晶 / Phase 3: Continuous Attack Crystal

目标：

- 新增水晶作为玩家本局成长基础战力。
- 水晶等级跟随本局历史最高等级。
- 水晶低频攻击最靠近终点的怪物。
- 解决后期低级合成攻击断档。

验收：

- 玩家合成出更高等级后，水晶表现会升级。
- 玩家继续合成低级数字时，水晶仍然保持基础输出。
- 水晶输出不会强到取代合成攻击。
- 游戏暂停、失败、弹窗时水晶攻击暂停。
- 重新开始会重置水晶等级和攻击计时。

## 阶段 4：颜色属性 / Phase 4: Color Elements

目标：

- 加入火焰、冰冻、雷电、毒。
- 接入持续伤害、冻结、连锁等基础效果。
- 补充对应视觉反馈。

## 阶段 5：UI 和反馈 / Phase 5: UI And Feedback

目标：

- 优化城堡耐久显示。
- 优化波次显示。
- 优化怪物受击、死亡、攻击飞行表现。
- 优化水晶升级和攻击表现。
- 调整布局，确保棋盘和怪物路径不冲突。

## 阶段 6：道具和技能 / Phase 6: Items And Skills

目标：

- 加入自动小道具。
- 加入主动大技能。
- 调整道具获取、触发和 UI。

## 建议优先执行顺序 / Recommended Order

1. 保持现有合成核心稳定。
2. 完成 BattleLayer / PathSystem / MonsterSystem 最小闭环。
3. 接入合成攻击事件。
4. 加入持续攻击水晶。
5. 再做属性、弹道、特效和 UI 细化。
