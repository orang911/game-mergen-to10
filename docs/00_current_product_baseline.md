# 当前产品基线 / Current Product Baseline

更新：2026-08-06  
适用：`game_mergenTo10_published`

> 本文是当前策划、研发、美术和测试的共同入口。与旧方案冲突时，以本文、`24_chapter_one_campaign.md`、`26_combat_balance_master.md` 和运行配置为准；历史实验、旧 20 波单关卡方案和未落地卡牌提案不再作为当前规则。

## 1. 产品目标

这是一个竖屏休闲数字合成塔防。玩家通过 5×5 棋盘合成数字发起攻击，守护唯一目标“水晶城堡”。

第一阶段目标不是扩展长线内容，而是让新玩家在第一章完成以下认知闭环：

```text
合成数字 → 攻击怪物 → 怪物威胁水晶 → 合成更高数字 → 使用印记 → 水晶强化 → 击败 Boss
```

## 2. 进入与局外流程

```text
启动 → 2.5 秒 Loading
├─ 新用户：直接进入 1-1 首波教学
└─ 老用户：进入大厅 → 点击关卡入口
    ├─ 有章节/续战存档：继续原样战斗
    ├─ 第一章完成：进入续战 01
    └─ 已完成续战：重新开始第一章
```

- Loading 没有“开始游戏”按钮；显示“正在加载”和百分比。
- 登录页左下角提供“清空本地数据”，用于重置新手测试。
- 章节进行中退出不视为失败；重启后恢复棋盘、怪物血量与路径、水晶、能量、待触发印记和卡牌状态。
- 玩家只在失败、主动返回或章节/续战完成后回到大厅。

## 3. 第一章《水晶初醒》

第一章是一局连续战斗：5 个节点、12 个波次，节点间继承棋盘、水晶耐久、能量、待触发印记和水晶强化。

| 节点 | 波次 | 当前职责 |
|---|---:|---|
| `1-1` | 3 | 水晶苏醒、基础合成、首次属性反馈与自由合成。首波为 4 只基础怪后出现突破怪；突破怪在水晶边界攻击一次，水晶苏醒并反击。 |
| `1-2` | 3 | 小/中怪压力递增；让玩家在实战中观察五种属性反馈。 |
| `1-3` | 3 | 印记教学：先固定获得星阶铸锤，再在星阶铸锤/王城魔炮中二选一。 |
| `1-4` | 2 | 护卫波与 120 HP 小 Boss；能量满时允许随机印记选择。 |
| `1-5` | 1 | 300 HP 大 Boss 与 3 只中型护卫；能量满时允许随机印记选择。 |

- 小 Boss 后固定获得 1 星“星核蒸汽炉”，水晶普通攻击伤害 `+10%`，持续到本局结束。
- Boss 第一版仅区分外观、尺寸、血条和数值，不含专属技能或多阶段。
- 第一章完成后可立即进入保留的 20 波“续战”，用于数值与节奏调试；续战不是第二章。
- 章节配置见 `scripts/chapter_one_config.gd`，完整验收见 `24_chapter_one_campaign.md`。

## 4. 核心战斗规则

- 棋盘：5×5；点击相邻同等级方块组成一组，再点击组内目标完成合成。
- 合成：目标块等级 `+1`，完成下落与补充，并产生一次合成攻击。
- 守护目标：水晶城堡，初始耐久 20；怪物触碰水晶边界即造成伤害并消失。
- 攻击目标：默认优先当前最靠近水晶的怪物。
- 失败：水晶耐久归零或棋盘无可合并时失败；章节重试恢复当前节点检查点。
- 复活：沿用失败结算入口；章节内恢复失败发生时的战斗快照，不重置整章。

### 五色属性

`绿色毒 → 蓝色冰冻 → 黄色闪电 → 紫色暴击 → 红色火焰`，每五级循环一次。

| 属性 | 当前规则 |
|---|---|
| 毒 | 合成 N 张产生 N 发连续集火；每次对存活目标的有效命中叠 1 层毒，最多 4 层；目标死亡后才切换。 |
| 冰冻 | 攻击前方 `N-1` 个不同目标；移速降至 40%，持续 2 秒。 |
| 闪电 | 仅 1 个主目标；额外合成量提升主伤害、弹跳次数和弹跳保留率；链路依次硬直约 1 秒。 |
| 暴击 | 每发独立判定暴击；另有随属性阶提高的普通怪湮灭概率。 |
| 火焰 | 每次命中和溅射都可叠加燃烧，最多 4 层。 |

毒与火的直接命中均会记录独立层；毒每秒结算一次合计伤害并显示一次红闪与飘字。所有精确数值以 `26_combat_balance_master.md` 和 `scripts/game_config.gd` 为准。

## 5. 能量、印记与水晶卡

### 能量与印记

- 能量上限 100。
- 能量来源：普通攻击击杀 `+5`；合成产出新的棋盘最高等级时，获得 `6 × (合成数量 - 1)`。
- 满能量、能量光点抵达 HUD 后打开选择；弹窗期间战斗暂停。
- 选择后得到一个“下一次有效合成”槽位，不再把印记附着到棋盘格。
- 下一次有效合成立即结算效果并消耗该槽位；已有待触发印记时不再开启第二个选择。

当前印记池：星阶铸锤、万象数盘、命运魔箱、双生晶模、王城魔炮、龙焰投石。

### 水晶卡

当前水晶卡池：炉心龙纹管、腐蚀炼金罐、星核蒸汽炉、迅流发条机、双塔折射镜、城墙穿透炮。

- 水晶初始为 1 级、每 1.8 秒攻击一次最前怪物，基础伤害为当前水晶等级攻击力的 30%。
- 第一章水晶开场为暗淡状态；突破怪第一次攻击后苏醒。
- “合成 3/5/7 自动升级水晶”的旧成长逻辑仍保留在代码，但当前新手/第一章关闭。
- 目标 16 张卡池仍是后续提案，当前未进入运行池。

## 6. 当前研发边界

本轮优先做“第一章首局体验与续战数值基线”，包括波次节奏、Boss 压力、能量到达时机、印记使用率、属性可读性和失败来源。

本轮暂不扩展：第二章、特殊怪 AI、Boss 主动技能、随机三选一水晶强化、永久水晶成长、16 张目标卡池、商业化和排行榜。
