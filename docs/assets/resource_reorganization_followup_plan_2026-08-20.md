## P1：治理运行目录未引用资源

### 已知事实

- 当前总账列出 189 个 `RUNTIME_UNREFERENCED` 资源。
- “静态未发现引用”不等于“确认可删除”，其中可能存在历史回退、动态加载遗漏或尚待接入资源。

### 执行内容

1. 按界面和模块拆分 189 个资源，优先处理旧 UI 目录。
2. 为每项标记“保留、已替代、待接入、可归档、可删除候选”。
3. 建立旧资源到当前替代资源的对应关系。
4. 先提交审核清单；获得明确批准后再执行归档或删除。

### 验收

- 每项都有证据、责任模块和处理结论。
- 未经审核不删除资源；处理后重新运行引用与导出校验。
