# 权益弹窗程序拼装说明 v01

## 使用范围

- 本包只包含美术生产素材，不包含场景接入、脚本修改或运行时资源替换。
- 所有标题、说明、价格、状态文字和数量标记均由程序绘制，便于本地化和状态切换。
- 参考效果图位于 `source/approved_effect_v01.png`。

## 比例与对齐

- 弹窗整体使用固定比例，不建议九宫格拉伸；以宽度等比缩放并居中。
- 两张权益卡必须使用相同尺寸、相同纵坐标和相同间距。
- 三个图标均为 512×512 同画布，节点中心点设为 `(0.5, 0.5)`；只改显示尺寸，不改单张贴图裁切。
- 参考拼装比例：弹窗壳宽 100%；标题条宽约 58%；单卡宽约 38%；两卡总宽约 80%。
- 安全区不要压到弹窗壳的圆角和内描边。

## 程序文字

- 标题、商品名：白字或深蓝字，按效果图使用描边或轻投影。
- 说明文字：深蓝灰色，禁止缩到不可读。
- “x2”“AD”、价格与按钮文案必须是独立 Label，不烘焙进图标或按钮。
- 购买中、购买失败、已拥有、恢复购买等状态复用同一套背板，通过文字、颜色调制和交互状态表达。
