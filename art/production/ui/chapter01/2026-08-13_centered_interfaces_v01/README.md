# 第一章居中界面切图 v01

本批以最终效果图的真实像素轮廓为唯一几何基准，包含 10 个居中打开界面：

- 战斗暂停
- 退出确认
- 设置
- 清空本地数据确认
- 日常任务
- 七日签到
- 权益
- 首充礼包
- 存钱罐
- 商城

## 使用规则

- 所有界面锚点与轴心均为 `(0.5, 0.5)`，实例打开位置为屏幕中心。
- 只允许等比缩放；禁止单轴拉伸。
- `reference_composites/` 为按效果图原像素裁出的透明参考母版，锁定宽高比、边框厚度、圆角、标题栏和按钮比例。
- 参考母版仍含效果图文字、数字和动态图素，不能作为正式运行时无字壳体直接安装。
- 正式壳体清理时不得改变 `manifest_reference_composites.json` 中登记的宽高比。

## 质检

- `qa/centered_interfaces_reference_contact_sheet.png`：透明棋盘底总览。
- `manifest_reference_composites.json`：尺寸、宽高比、中心轴心和来源裁框。

大厅主画面不是弹窗，因此未作为本批独立居中界面切图。
